# Third Stint Racing — Partnerdossier Onepager

Statische HTML/CSS/JS onepager gebaseerd op het partnerdossier PDF.

## Openen

```
open index.html
```

Of serveer lokaal:

```
python3 -m http.server 8000
```

En ga naar http://localhost:8000.

## Structuur

- `index.html` — markup (Nederlands, verbatim uit PDF)
- `styles.css` — design tokens, grid, responsive
- `main.js` — IntersectionObserver animaties (count-up, reveal, nav)
- `assets/images/` — foto's geëxtraheerd uit PDF
- `assets/pages/` — page renders PDF (reference)
- `assets/favicon.svg`
